Política de Privacidade

Última atualização: 2026-06-06 — Versão 1.1

Esta Política de Privacidade descreve como o aplicativo Spark Base — Instagram Agent (aqui chamado de "o Serviço") coleta, armazena, processa e protege informações relacionadas ao uso da automação de mensagens diretas (DMs), comentários e menções do Instagram via Meta Graph API.

O Serviço é operado por Jonathan Camino (aqui chamado de "Controlador"). Para questões de privacidade, contato: joncarvv@gmail.com.

1. Quem usa o Serviço

O Serviço é utilizado pelo Controlador para automatizar respostas em sua própria conta Instagram Business, vinculada via OAuth oficial da Meta. Usuários do Instagram que enviam mensagens à conta conectada são considerados "Usuários Finais" e seus dados são processados conforme descrito abaixo.

2. Dados coletados

Quando um Usuário Final envia uma DM, comenta em um post ou interage com Stories da conta Instagram Business conectada, o Serviço pode coletar:

  • Identificador IGSID (Instagram-Scoped User ID) — identificador único fornecido pela Meta que vincula o usuário ao app, sem expor a conta pública.
  • Conteúdo da mensagem ou comentário (texto, ID de mídia anexada).
  • Metadados do evento (timestamp, ID da mensagem, tipo de evento).
  • Informações públicas do perfil quando disponíveis via Graph API (nome de exibição, foto, contadores) — apenas quando o Usuário Final inicia uma conversa.

O Serviço não coleta: senhas, contatos do dispositivo, localização precisa, dados de pagamento, ou qualquer informação não relacionada à interação com a conta Instagram conectada.

3. Como os dados são usados

  • Gerar respostas automatizadas via inteligência artificial (Anthropic Claude API) para responder DMs em nome do Controlador.
  • Manter histórico de conversa por até 90 dias para contexto entre mensagens.
  • Identificar comentários com palavras-gatilho cadastradas e disparar resposta privada (DM).
  • Calcular métricas agregadas (volume de DMs, taxa de resposta) para o painel administrativo.

Dados não são vendidos, não são usados para anúncios, e não são compartilhados com terceiros exceto quando estritamente necessário para a operação do Serviço (ver Seção 5).

4. Armazenamento e segurança

Adotamos controles técnicos compatíveis com práticas atuais de segurança de aplicações:

  • Banco de dados: SQLite hospedado em VPS dedicada, volumes persistentes isolados por aplicação. Acesso ao servidor restrito ao Controlador via SSH com chave pública (sem senha).
  • Tokens da Meta (page access token, user access token) criptografados em repouso com AES-256-GCM. A chave de criptografia é dedicada (META_TOKEN_KEY, 256 bits gerada via CSPRNG) ou derivada via scrypt em deploys legados — separada da chave de assinatura de sessão.
  • Sessões: cookies HttpOnly + Secure + SameSite=Strict. Tokens de sessão não são acessíveis via JavaScript (à prova de XSS) e não viajam em URLs, query strings ou cabeçalhos Authorization que possam vazar em logs ou referers.
  • 2FA (TOTP) opcional via aplicativo autenticador padrão (Google Authenticator, Authy, 1Password). Tentativas de verificação 2FA limitadas a 5/15min/usuário para prevenir brute force.
  • Senhas de administrador armazenadas como hash bcrypt com cost 12. Mínimo 12 caracteres, validação de força via zxcvbn. Lockout progressivo após tentativas falhas.
  • Cabeçalhos de segurança HTTP: HSTS com preload, CSP restritivo, X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff. Configurados via helmet.
  • Rate limiting aplicado a login, registro, verificação 2FA, criação de usuários (admin) e endpoints de API gerais.
  • Comunicação cliente-servidor: HTTPS (TLS 1.2+) com certificado Let's Encrypt e renovação automática. Tráfego interno do container restrito.
  • Validação SSRF: requisições HTTP iniciadas pelo Serviço (ex: análise de site para enriquecimento de contexto) validam o destino contra ranges privados via regex + resolução DNS, e bloqueiam redirects para endereços internos.
  • Validação de entrada do usuário no LLM: nomes e textos vindos de Usuários Finais são sanitizados antes de compor prompts ao modelo, evitando ataques de prompt injection.

5. Compartilhamento com terceiros

Para gerar respostas automáticas, conteúdo de mensagens pode ser enviado a:

  • Anthropic (Claude API) — política. Apenas o texto da mensagem é enviado; nenhum identificador pessoal é compartilhado. A Anthropic se compromete contratualmente a não treinar modelos com dados de API.
  • Meta Platforms — para enviar respostas via Instagram Graph API. Aplicável aos termos da própria Meta.
  • Google (opcional) — quando o usuário usa a funcionalidade de agendamento via Google Calendar/Meet, apenas dados estritamente necessários ao agendamento são enviados.

6. Retenção de dados

  • Mensagens e conversas: até 90 dias após a última interação, depois excluídas automaticamente por job programado.
  • Logs de auditoria (registros de acesso ao painel, ações administrativas): até 180 dias, então rotacionados. Conteúdo de mensagens nunca aparece em logs (sanitização automática remove campos sensíveis).
  • Tokens de acesso Meta: enquanto a conta estiver conectada. Ao desconectar (via revogação no Instagram ou via painel administrativo), são excluídos imediatamente.
  • Cookies de sessão: TTL de 24 horas no navegador do administrador.

7. Direitos do Usuário Final (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018), Usuários Finais têm direito a:

  • Confirmar a existência de tratamento de seus dados.
  • Acessar seus dados.
  • Solicitar correção de dados incompletos ou desatualizados.
  • Solicitar anonimização, bloqueio ou eliminação de dados desnecessários.
  • Solicitar portabilidade.
  • Solicitar exclusão completa.

Para exercer qualquer destes direitos, envie email para joncarvv@gmail.com com seu @ do Instagram. A solicitação será atendida em até 15 dias úteis.

8. Como solicitar exclusão (Data Deletion)

Para que seus dados sejam apagados do nosso sistema:

  • Envie email para joncarvv@gmail.com com assunto "Exclusão de dados — <seu @ Instagram>".
  • Ou revogue a permissão do app diretamente no Instagram em Configurações > Apps e sites > Spark Base-IG > Remover.

Em ambos os casos, todos os dados associados ao seu IGSID serão excluídos em até 30 dias.

9. Menores de idade

O Serviço não é direcionado a menores de 13 anos. Caso o Controlador identifique a coleta inadvertida de dados de menores, os dados serão excluídos imediatamente.

10. Alterações nesta Política

Esta política pode ser atualizada para refletir mudanças no Serviço ou requisitos legais. Mudanças significativas serão comunicadas via aviso no painel administrativo. A versão atual está sempre disponível em /privacy.
